# CKZ przewoźnika drogowego — банк вопросов и тренажёр

Проект для подготовки к экзамену на Certyfikat Kompetencji Zawodowych przewoźnika drogowego (Certificate of Professional Competence автомобильного перевозчика). Содержит банк из 800 вопросов, перенесённых из книги (Denali), и JS-тренажёр для подготовки.

## Ветка `web-deploy`: раздельная выдача public/private

В этой ветке приложение рассчитано на запуск с веб-сервера, где HTML-страница и файл с вопросами хранятся и отдаются раздельно:

- `public/index.html` — тот же тренажёр (режимы тренировки и экзамена: 64 вопроса / 2 часа, по 8 из каждой из 8 тематических групп), но **без встроенных данных**. При старте он делает `fetch(DATA_URL)` (по умолчанию `DATA_URL = '../private/questions.json'`, см. начало `<script>` в файле) и ждёт ответа с тем же JSON, что и в `private/questions.json`.
- `private/questions.json` — банк вопросов и ответов. Этот файл не предназначен для прямой раздачи как статика из публичной папки — заложите его вне docroot (например, на уровень выше `public/`, как подсказывает путь `../private/questions.json`) и отдавайте по этому же относительному пути, либо поменяйте `DATA_URL` в `public/index.html` на абсолютный путь/роут, через свой бэкенд или правило веб-сервера. Как именно ограничивать доступ (авторизация, IP-фильтр, отдельный internal-роут и т.п.) — на стороне вашей инфраструктуры, в этой ветке заложена только сама раздельная структура файлов и загрузка через `fetch`.

Если `fetch` не удался (сеть, 404, сервер не настроен), страница покажет сообщение об ошибке с указанием пути, по которому она пыталась получить данные, а не упадёт молча.

## Ветка `main`: самодостаточный файл

В `main` лежит версия, где `app/ckz-trenazher.html` — один файл со встроенным JSON (запускается просто открытием в браузере, без сервера), и `data/ckz_przewoznika_test_001_800.json` — тот же набор данных отдельно, как исходник.

## Структура (общая для обеих веток)

- вопросы: `id`, `question`, `options` (A–D), `correct` — текст перенесён из книги как напечатан (без исправления опечаток оригинала; технические артефакты переноса исправлены — см. `docs/ckz_przewoznika_notes.md`, раздел 9а).
- `docs/ckz_przewoznika_notes.md` — отчёт о спорных местах при переносе текста из книги: опечатки и особенности книги, повторяющиеся вопросы, противоречие в ключе ответов (вопросы 28/531), что не вошло (раздел «Zadania kadrowe»), какие технические правки внесены в текст.
- `docs/ckz_przewoznika_analiza_aktualnosci.pdf` — выборочный анализ актуальности части ответов относительно действующего польского/ЕС законодательства (на дату анализа). Ответы в JSON не исправлены по итогам этого анализа — ключ книги оставлен как официальный источник для сдачи экзамена.

## Важно

- Ответы (`correct`) взяты из официального ключа книги (стр. 132–134) и не корректировались ни по орфографии, ни по актуальности законодательства — решение пользователя: цель — сдать экзамен по этой книге, а не оспаривать её.
- Раздел книги «Zadania kadrowe» (расчётные задачи без вариантов A–D) в банк не включён.

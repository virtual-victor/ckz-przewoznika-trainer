# CKZ przewoźnika drogowego — банк вопросов и тренажёр

Проект для подготовки к экзамену на Certyfikat Kompetencji Zawodowych przewoźnika drogowego (Certificate of Professional Competence автомобильного перевозчика). Содержит банк из 800 вопросов, перенесённых из книги (Denali), и JS-тренажёр для подготовки.

## Структура репозитория

- `data/ckz_przewoznika_test_001_800.json` — банк вопросов (id, question, options A–D, correct) на польском языке, текст перенесён из книги как напечатан (без исправления опечаток оригинала; технические артефакты переноса исправлены — см. `docs/ckz_przewoznika_notes.md`, раздел 9а).
- `app/ckz-trenazher.html` — самодостаточный HTML/JS-тренажёр (без зависимостей, кроме Google Fonts): режим свободной тренировки (рандомные вопросы, одно- и многовариантные ответы, немедленная проверка) и режим экзамена (30 вопросов за 2 часа, с таймером, навигацией по вопросам и разбором результатов). Данные встроены в файл.
- `docs/ckz_przewoznika_notes.md` — отчёт о спорных местах при переносе текста из книги: опечатки и особенности книги, повторяющиеся вопросы, противоречие в ключе ответов (вопросы 28/531), что не вошло (раздел «Zadania kadrowe»), какие технические правки внесены в текст.
- `docs/ckz_przewoznika_analiza_aktualnosci.pdf` — выборочный анализ актуальности части ответов относительно действующего польского/ЕС законодательства (на дату анализа). Ответы в `data/...json` не исправлены по итогам этого анализа — ключ книги оставлен как официальный источник для сдачи экзамена.

## Важно

- Ответы (`correct`) взяты из официального ключа книги (стр. 132–134) и не корректировались ни по орфографии, ни по актуальности законодательства — решение пользователя: цель — сдать экзамен по этой книге, а не оспаривать её.
- Раздел книги «Zadania kadrowe» (расчётные задачи без вариантов A–D) в банк не включён.
